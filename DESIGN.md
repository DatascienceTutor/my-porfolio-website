# Design System

## Typography
- **Primary (Sans):** Inter
- **Monospace:** JetBrains Mono

## Color Palette

### Surface
- `surface`: `#f8fafc` (Background)
- `surface-card`: `#ffffff` (Card background)
- `surface-subtle`: `#f1f5f9`
- `surface-muted`: `#e2e8f0`

### Primary
- `primary`: `#1d4ed8`
- `primary-hover`: `#1e40af`
- `primary-light`: `#eff6ff`
- `primary-container`: `#1d4ed8`
- `on-primary`: `#ffffff`
- `on-primary-container`: `#ffffff`

### Text & Navy
- `navy-dark`: `#0f172a`
- `navy-deep`: `#090d16`
- `text-primary`: `#0f172a`
- `text-secondary`: `#334155`
- `text-muted`: `#64748b`

### Borders
- `border-subtle`: `#e2e8f0`
- `border-card`: `#e2e8f0`

### Accents / Badges
- `tertiary`: `#0f766e`
- `badge-blue-bg`: `#eff6ff`
- `badge-blue-text`: `#1d4ed8`
- `badge-teal-bg`: `#f0fdf4`
- `badge-teal-text`: `#15803d`

## Border Radius
- `DEFAULT`: `0.25rem`
- `lg`: `0.5rem`
- `xl`: `0.75rem`
- `2xl`: `1rem`
- `full`: `9999px`

## Iconography
- **Lucide React** (Replaces Material Symbols Outlined used in the original prototype)

## Animation
- **Framer Motion** for subtle scroll and fade transitions (smooth scrolling for anchors is implemented via CSS `scroll-behavior: smooth` + `framer-motion` for reveal effects).
